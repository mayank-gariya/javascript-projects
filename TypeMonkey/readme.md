# 🐒 Monkeytype Clone

A clean, fast, and feature-rich minimalist typing test web application inspired by [Monkeytype](https://monkeytype.com/), built using **Python/Flask**, **Tailwind CSS**, and **Vanilla JavaScript**.

![Project Banner / Preview](https://img.shields.io/badge/status-completed-success) ![Python](https://img.shields.io/badge/backend-Flask-blue) ![JavaScript](https://img.shields.io/badge/frontend-Vanilla%20JS-yellow) ![Tailwind CSS](https://img.shields.io/badge/styling-Tailwind%20CSS-38bdf8)

---

## ✨ Features

- **⏱️ Multiple Test Modes:**
  - **Time Mode:** Test your speed over customizable durations (`15s`, `30s`, `60s`).
  - **Quote Mode:** Practice typing classic, hand-picked motivational quotes.
- **⚙️ Dynamic Modifiers:**
  - **Punctuation Toggle:** Inject commas, periods, question marks, and capitalization dynamically into word generators.
  - **Numbers Toggle:** Randomly include numbers to test your alphanumeric typing coordination.
- **📊 Real-Time Analytics & Results:**
  - Live blinking caret cursor tracking your exact progress.
  - Instant character-level color feedback (muted gray for upcoming, white for correct, red for errors).
  - Detailed summary screen calculating final **WPM (Words Per Minute)** and **Accuracy percentage** upon completion.
- **⌨️ Keyboard Shortcuts:**
  - Press `Tab` instantly to restart the test at any time.
- **🎨 Sleek Dark-Mode UI:** Designed with Monkeytype’s iconic aesthetic using a custom dark theme (`#111111`) and vibrant accent colors (`#e2b714`).

---

## 🛠️ Tech Stack

- **Backend:** Python (Flask web framework)
- **Frontend Styling:** Tailwind CSS (via CDN)
- **Client-Side Logic:** Vanilla JavaScript (DOM manipulation, event listeners, timer intervals)
- **Markup & Layout:** HTML5
